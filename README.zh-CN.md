Steam Shelf 读取本地 Steam 库，把所有已安装的游戏以封面图网格呈现。点击封面即可开始游戏。再点一下，它会为每款游戏在 `~/Applications` 中生成真正的 `.app` 包，于是游戏会和其他应用一样出现在启动台和聚焦搜索里，不必再绕道 Steam 窗口。

它是一个没有第三方依赖的单一 SwiftUI 二进制文件，一条 `swiftc` 命令即可构建，也没有需要打开的 Xcode 工程。

## 功能

- **封面图网格** —— 直接使用 Steam 自带的本地缓存，离线可用；仅缺失的封面会从 Steam CDN 下载一次并缓存。
- **一键启动** —— 点击封面会打开官方启动路径 `steam://rungameid/<appid>`，云存档、游戏时长和游戏内覆盖层均照常工作。
- **逐游戏 `.app` 快捷方式** —— 把已安装的游戏同步到 `~/Applications`，并附带封面图标，可直接从启动台和聚焦搜索启动。
- **安全清理** —— 已卸载游戏的快捷方式会被移到废纸篓而非直接删除，并且只会处理 Steam Shelf 能够确认由自己管理的包。
- **实时跟随** —— 监听 `steamapps` 目录，安装或删除游戏后无需重启即可刷新网格。
- **多库支持** —— 依据 `libraryfolders.vdf` 读取外置硬盘和第二库目录。
- **搜索与排序** —— 按名称筛选，按最近游玩、名称或占用空间排序。
- **多语言** —— 跟随系统语言，支持英语、韩语、日语和简体中文。

## 安装

### 下载

从[最新发行版](https://github.com/2JIHAN/steam-shelf/releases/latest)下载 `SteamShelf-x.y.z-universal.zip`，解压后把 **Steam Shelf.app** 移动到「应用程序」文件夹。

该应用只做了 ad-hoc 签名，**未经过公证（notarization）**，因此首次打开时会被 macOS 拦截。清除一次隔离属性即可：

```bash
xattr -dr com.apple.quarantine "/Applications/Steam Shelf.app"
```

或者打开**系统设置 → 隐私与安全性**，找到关于 Steam Shelf 的提示，点击**仍要打开**。

### 从源码构建

```bash
git clone https://github.com/2JIHAN/steam-shelf.git
cd steam-shelf
./build.sh
```

应用会生成在 `~/Applications/Steam Shelf.app`。若要安装到别处或指定架构：

```bash
./build.sh /Applications          # 安装到 /Applications
ARCHS=arm64 ./build.sh            # 跳过 Intel 切片，构建更快
```

本机构建的应用不会带上隔离属性，Gatekeeper 不会拦截。

## 使用

| 操作 | 效果 |
|---|---|
| 点击封面 | 启动游戏 |
| 右键封面 | 启动 · 打开安装目录 · 打开商店页面 · 复制 AppID |
| <kbd>⌘</kbd><kbd>R</kbd> | 重新加载游戏库 |
| <kbd>⇧</kbd><kbd>⌘</kbd><kbd>S</kbd> | 同步快捷方式 |
| 搜索框 | 按游戏名筛选 |
| 排序菜单 | 最近游玩 · 名称 · 占用空间 |

## 快捷方式同步

按 <kbd>⇧</kbd><kbd>⌘</kbd><kbd>S</kbd> 或点击工具栏按钮，Steam Shelf 会为每款已安装游戏在 `~/Applications` 写入一个 `.app` 包：

```
~/Applications/Hollow Knight - Silksong.app
└── Contents
    ├── Info.plist                 # SteamShelfAppID 标记 + 游戏元数据
    ├── MacOS/run.sh               # open "steam://rungameid/1030300"
    └── Resources/icon.icns        # 由游戏封面生成
```

文件名中的非法字符会被替换：`Hollow Knight: Silksong` 会变成 `Hollow Knight - Silksong.app`，但聚焦搜索仍能按原名找到它。

### 它会动哪些文件

同步只把两类包视为自己的产物：

| 类型 | 识别方式 |
|---|---|
| Steam Shelf 创建的 | `Info.plist` 中的 `SteamShelfAppID` 键 |
| Steam「Add to Applications」创建的 | `run.sh` 中的 `autogenerated file` 标记及 `steam://run` 链接 |

`~/Applications` 中的其他应用一概不动。如果某个普通应用已经占用了游戏想用的名字，该游戏会被跳过并在结果中列出，而不会被覆盖。已卸载游戏的快捷方式进入废纸篓，随时可以恢复。

## 工作原理

| 环节 | 做法 |
|---|---|
| 查找游戏库 | 解析 `steamapps/libraryfolders.vdf` 获取全部库根目录 |
| 枚举游戏 | 解析每个 `appmanifest_*.acf`，读取 appid、名称、体积和最近游玩时间 |
| 判定是否已安装 | 要求 `steamapps/common/<installdir>` 实际存在，从而排除排队下载的条目 |
| 封面图 | 在 `appcache/librarycache/<appid>` 下查找 `library_600x900` / `library_capsule` / `library_header`，找不到则回退到 Steam CDN 并缓存到 `~/Library/Application Support/SteamShelf/covers` |
| 启动 | `steam://rungameid/<appid>` |
| 保持同步 | 用 `DispatchSource` 监听各 `steamapps` 目录，变动时重新加载 |
| 图标 | 将封面裁成正方形，通过 ImageIO 写出 `.icns` |

## 支持的语言

界面跟随 macOS 系统语言，未覆盖的语言回退到英语。

| 语言 | 状态 |
|---|---|
| English | 开发语言 |
| 한국어 | 完整 |
| 日本語 | 完整 |
| 简体中文 | 完整 |

若要新增语言，把 `Resources/en.lproj/Localizable.strings` 复制到 `Resources/<语言代码>.lproj/`，只翻译每行等号右侧的内容，再把语言代码加入 `build.sh` 的 `CFBundleLocalizations`。无需改动 Swift 代码。

## 常见问题

### Steam 仍然需要运行吗？

需要。Steam Shelf 不绕过 Steam——它请求 Steam 启动游戏，与在客户端里点击「开始游戏」完全一致。正因如此，云存档、成就、游戏时长和覆盖层才能正常工作。若 Steam 未运行，它会自动启动。

### 执行「同步快捷方式」安全吗？

只有带 Steam Shelf 标记或 Steam 自身 autogenerated 标记的包才会被移除，而移除的含义是移到废纸篓。除读取 `Info.plist` 外，不会对其他应用做任何操作。

### 封面图来自哪里？

Steam 本身已把库封面缓存在磁盘上，因此会先查本地，这种情况下完全不走网络。只有本地没有封面的游戏才会从 Steam CDN 下载一次。

### 为什么要求 macOS 14 及以上？

界面用到了 Sonoma 引入的 SwiftUI API。降低部署目标意味着要重写工具栏和窗口处理的大部分逻辑，代价与收益不成比例。

### 支持非 Steam 游戏吗？

暂不支持。Steam Shelf 读取的是 Steam 自己的清单，因此只显示通过 Steam 安装的游戏。位于第二库或外置硬盘上的 Steam 游戏则完全支持。
