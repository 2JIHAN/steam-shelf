Steam Shelf はインストール済みの Steam ゲームをカバーアートのグリッドで表示します。タイルをクリックすればプレイできます。もう一度クリックすれば、ゲームごとに本物の `.app` を `~/Applications` に作成し、Launchpad や Spotlight から他のアプリと同じように起動できます。

## 特徴

- **カバーアートのグリッド** — Steam のローカルキャッシュを使うためオフラインでも動作。無いアートだけ Steam CDN から一度取得します。
- **ワンクリック起動** — `steam://rungameid/<appid>` を開くので、クラウドセーブ・プレイ時間・オーバーレイはそのまま機能します。
- **ゲームごとの `.app` ショートカット** — カバーアートのアイコン付きで、Launchpad と Spotlight からすぐ起動できます。
- **安全なクリーンアップ** — アンインストール済みゲームのショートカットはゴミ箱へ。Steam Shelf が自分の管理下だと確認できたバンドルにしか触れません。
- **ライブラリの自動追従** — ゲームの追加・削除は再起動なしで反映されます。
- **複数ライブラリ対応** — 外付けドライブを含みます。
- **検索と並べ替え** — 最終プレイ・名前・使用容量。
- **4 言語** — English、한국어、日本語、简体中文。

## インストール

[最新リリース](https://github.com/2JIHAN/steam-shelf/releases/latest)から `SteamShelf-x.y.z-universal.zip` を入手し、展開して **Steam Shelf.app** をアプリケーションフォルダへドラッグし、開いてください。

### ソースからビルド

```bash
git clone https://github.com/2JIHAN/steam-shelf.git
cd steam-shelf
./build.sh                        # → ~/Applications/Steam Shelf.app
./build.sh /Applications          # 別の場所にインストール
ARCHS=arm64 ./build.sh            # Intel スライスを省略
```

Swift 6（Xcode Command Line Tools）が必要です。署名済みリリースを作るには `NOTARY_PROFILE=<notarytool プロファイル> ./release.sh`。

## 使い方

| 操作 | 動作 |
|---|---|
| タイルをクリック | ゲームを起動 |
| タイルを右クリック | 起動 · インストールフォルダを表示 · ストアページを開く · AppID をコピー |
| <kbd>⌘</kbd><kbd>R</kbd> | ライブラリを再読み込み |
| <kbd>⇧</kbd><kbd>⌘</kbd><kbd>S</kbd> | ショートカットを同期 |
| 検索フィールド | ゲーム名で絞り込み |
| 並べ替えメニュー | 最終プレイ · 名前 · 使用容量 |

## ショートカット同期

<kbd>⇧</kbd><kbd>⌘</kbd><kbd>S</kbd> を押すと、インストール済みゲームごとに `.app` が `~/Applications` に作られます。アイコンはカバーアートから生成されます。ファイル名に使えない文字は置き換えられ、`Hollow Knight: Silksong` は `Hollow Knight - Silksong.app` になります。

同期が自分のものとして認識するバンドルは次の 2 種類だけです。

| 種類 | 判別方法 |
|---|---|
| Steam Shelf が作成したもの | `Info.plist` の `SteamShelfAppID` キー |
| Steam の「Add to Applications」が作成したもの | `run.sh` 内の `autogenerated file` マーカーと `steam://run` URL |

`~/Applications` にあるそれ以外のアプリには手を付けません。ゲームが使いたい名前を通常のアプリが既に占有している場合は、上書きせずにスキップして結果に報告します。アンインストール済みゲームのショートカットはゴミ箱へ移動するので復元できます。

## 対応言語

システム言語に従い、未対応の言語では英語になります。言語を追加するには、`Resources/en.lproj/Localizable.strings` を `Resources/<コード>.lproj/` にコピーし、各行の右辺だけを翻訳して、`build.sh` の `CFBundleLocalizations` にコードを追加します。Swift 側の変更は不要です。

## プロジェクト構成

```
Sources/
  App.swift            アプリのエントリポイントとメニューコマンド
  ContentView.swift    グリッド UI、ゲームタイル、同期結果の文面
  Store.swift          状態管理、カバー読み込み、フォルダ監視
  SteamLibrary.swift   ライブラリとマニフェストの走査
  Artwork.swift        カバー検索、CDN フォールバック、.icns 生成
  ShortcutSync.swift   .app ショートカットの作成と整理
  VDF.swift            Steam KeyValues パーサー
Resources/             en, ko, ja, zh-Hans .lproj
build.sh               ビルドスクリプト
release.sh             署名・公証・パッケージング
```

## FAQ

### Steam は起動している必要がありますか？

はい。Steam Shelf はクライアントでプレイボタンを押すのとまったく同じように、Steam に起動を依頼します。そのおかげでクラウドセーブ、実績、プレイ時間、オーバーレイが正常に機能します。Steam が起動していない場合は自動的に立ち上がります。

### 「ショートカット同期」を実行しても安全ですか？

削除対象は Steam Shelf のマーカー、または Steam 自身の autogenerated マーカーを持つバンドルだけで、削除はゴミ箱への移動です。他のアプリには `Info.plist` を読む以外に触れません。

### Steam 以外のゲームには対応していますか？

いいえ。Steam のマニフェストを読むため、Steam でインストールしたゲームのみが表示されます。セカンダリライブラリや外付けドライブ上の Steam ゲームは問題なく動作します。
